# MOTChallenge Pedestrian Tracking Benchmark (MOT16 / MOT17 / MOT20)

## Official Source & Metadata
- **Dataset Name:** Multiple Object Tracking Benchmark (MOTChallenge MOT16 / MOT17)
- **Year:** 2016–2020
- **Domain:** Surveillance & Urban Pedestrian Tracking (Fixed & Moving Cameras)
- **Official Host:** MOTChallenge (Milan et al. / TU Munich & Adelaide)
- **License:** Open Academic Evaluation & Benchmark License
- **Intended Purpose:** Multi-person detection, track ID continuity, occlusion recovery, trajectory generation.

## Privacy & Ethics Rule
- Dataset entities are strictly anonymous track IDs (`PUBLIC_MOT:TRACK_102`, `PUBLIC_MOT:TRACK_103`).
- **NEVER** link MOT tracks to real-world names or synthetic criminal entities.
- Used exclusively for tracking metrics validation: MOTA (Multiple Object Tracking Accuracy), IDF1, ID Switches.
