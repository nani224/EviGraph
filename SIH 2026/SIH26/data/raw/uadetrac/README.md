# UA-DETRAC Traffic Surveillance Dataset

## Official Source & Metadata
- **Dataset Name:** University at Albany DETRAC Benchmark (UA-DETRAC)
- **Version:** v1.0 / DETRAC-test
- **Year:** 2016–2020 Benchmark
- **Collection Period:** Real-world traffic overpasses & intersections
- **Domain:** Traffic CCTV Surveillance (100 video sequences, 140,000 frames, 8,250 vehicles)
- **Official Host:** University at Albany / IEEE AVSS
- **License:** Research & Academic Benchmark Use
- **Intended Purpose:** Vehicle detection, multi-vehicle tracking, vehicle type classification (car, bus, van, other), occlusion handling.

## Important Note on License Plates
- This dataset is designed for vehicle detection and trajectory tracking; license plates are blurred or not annotated.
- Output rule: Display `Plate: Not available (Research Benchmark)`.
- Never synthesize or fabricate license plates on public benchmarks.
- **Dataset Namespace:** `PUBLIC_UADETRAC:`
